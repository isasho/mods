# 绯血者（Bloodbinder）美术需求文档

## 整体视觉方向

| 要素 | 方向 |
|------|------|
| 主色调 | 绯红/深红/暗红，辅以暗紫、黑金 |
| 视觉母题 | 血液操控、血管纹理、暗红水晶、新月、锁链 |
| 光影 | 低照度、高对比，类似烛光或血月下的氛围 |
| 风格参考 | 哥特暗黑 + 东方血术，介于 Ironclad 的粗犷与 Silent 的诡秘之间 |
| 材质纹理 | 液态血液流动感、凝固血痂、金属反光带暗红 |

## 四、统一交付规格

- 卡牌肖像：**1000×760** PNG，透明背景或暗色底均可
- 能力图标：**64×64** PNG，透明背景
- 遗物图标：**128×128** PNG，透明背景
- 药水图标：**64×64** PNG，透明背景
- UI 图标：各尺寸见上，PNG 透明背景
- Godot .import 文件自动生成，美术只需交付 PNG
